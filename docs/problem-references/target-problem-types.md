# Target Problem Types

This document organizes the paper-problem families that are a good fit for the app.

The common theme is that the child learns by seeing a transformation, manipulating an object, or understanding a spatial relation that changes over time.

## Progression

The app should introduce problem families in this order:

1. Stage 1: touch and understand
2. Stage 2: match the example
3. Stage 3: predict the result of a change
4. Stage 4: answer in A/B/C or another paper-style format

## Priority Overview

- P0: Rotation
- P0.5: Ferris Wheel / cyclic position tracking
- P1: Mirror, Folding, Layering
- P2: Water reflection, Shadow, Shape construction
- P3: Dice net, Cross-section, Perspective / blocks

## Rotation

### Paper problem pattern

The question asks which direction a shape, arrow, or object points after it is turned.

### Cognitive skill

Mental rotation, orientation tracking, and one-step spatial transformation.

### Interactive translation

Let the child tap or drag to rotate an object in fixed steps until it matches a reference.

### Fit for current app

- P0

### Example source PDFs

- `NSPL-kaitenzukei.pdf`
- `NSPL-kanransha.pdf`

## Ferris Wheel / cyclic position tracking

### Paper problem pattern

The question asks where an object or person ends up after repeated movement around a circular path.

### Cognitive skill

Sequence tracking, cyclic movement, and relative position awareness.

### Interactive translation

Show a wheel or loop and let the child advance items step by step to predict the next location.

### Fit for current app

- P0.5

### Example source PDFs

- `NSPL-kanransha.pdf`

## Mirror / Symmetry

### Paper problem pattern

The question asks what appears on the opposite side of a mirror axis or what shape completes a symmetric figure.

### Cognitive skill

Left-right reversal, symmetry recognition, and axis awareness.

### Interactive translation

Let the child drag a shape across a mirror line and see the reflected result immediately.

### Fit for current app

- P1

### Example source PDFs

- `NSPL-sentaisho.pdf`

## Water reflection

### Paper problem pattern

The question asks how an object looks when reflected on a water surface or a horizontal reflection line.

### Cognitive skill

Vertical reflection, inversion, and relation between source and reflected image.

### Interactive translation

Animate an object above a water line and let the child predict or build the reflected shape below it.

### Fit for current app

- P2

### Example source PDFs

- `NSPL-suimen.pdf`

## Folding

### Paper problem pattern

The question asks what happens when paper is folded and then opened again.

### Cognitive skill

Transforming a flat sheet into a folded state and reasoning about hidden and revealed parts.

### Interactive translation

Let the child fold a paper shape and then unfold it to inspect the result.

### Fit for current app

- P1

### Example source PDFs

- `NSPL-origamitenkai.pdf`
- `NSPL-sentaisho.pdf`

## Layering

### Paper problem pattern

The question asks which parts are in front, behind, or hidden when shapes overlap.

### Cognitive skill

Occlusion reasoning, depth ordering, and partial visibility.

### Interactive translation

Let the child stack shapes and peel them apart or reorder layers to match a target view.

### Fit for current app

- P1

### Example source PDFs

- `NSPL-kasanezukei.pdf`
- `NSPL-kagenokatachi.pdf`

## Shadow

### Paper problem pattern

The question asks which shadow belongs to an object or which object could cast a given shadow.

### Cognitive skill

Shape abstraction, silhouette matching, and transformation under light direction.

### Interactive translation

Let the child move a light source or rotate an object to see the shadow change.

### Fit for current app

- P2

### Example source PDFs

- `NSPL-kagenokatachi.pdf`

## Dice net / cube development

### Paper problem pattern

The question asks which flat net folds into a cube or which face ends up opposite another face.

### Cognitive skill

3D unfolding and folding, adjacency, and opposite-face reasoning.

### Interactive translation

Let the child fold a net into a cube in stages and compare the visible faces.

### Fit for current app

- P3

### Example source PDFs

- `NSPL-saikorotenkai.pdf`

## Cross-section

### Paper problem pattern

The question asks what shape appears when a solid is cut.

### Cognitive skill

Section reasoning, spatial decomposition, and 3D visualization.

### Interactive translation

Let the child move a cutting plane through a model and inspect the slice that appears.

### Fit for current app

- P3

### Example source PDFs

- `NSPL-kirikuchi.pdf`

## Shape construction

### Paper problem pattern

The question asks how to assemble or combine pieces to make a target shape.

### Cognitive skill

Part-whole reasoning, composition, and spatial fitting.

### Interactive translation

Let the child place pieces into an outline or combine blocks and polygons until they match the goal.

### Fit for current app

- P2

### Example source PDFs

- `NSPL-zukeikousei.pdf`
- `NSPL-sankakupuzzle.pdf`

## Perspective / blocks

### Paper problem pattern

The question asks what a block structure looks like from the front, side, or top.

### Cognitive skill

Viewpoint switching, height reasoning, and hidden-structure inference.

### Interactive translation

Let the child rotate a block model, switch viewpoints, and compare the visible faces.

### Fit for current app

- P3

### Example source PDFs

- `NSPL-tsumikinokazu.pdf`
