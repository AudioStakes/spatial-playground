# Problem References

This directory is for abstracted analysis of local paper-problem PDFs.

It is not a storage location for the PDFs themselves.

Use this area to:

- summarize the problem types found in the reference PDFs
- classify which problem types fit the app now, later, or not at all
- capture self-made design notes that do not copy problem text or figures

Keep the repository safe by following these rules:

- do not copy PDF pages, images, or question text into this directory
- do not treat reference PDFs as app assets
- do not present copied workbook or exam material as original content

Read this directory before designing a new game type so the interaction stays aligned with the visual-spatial scope of the app.
