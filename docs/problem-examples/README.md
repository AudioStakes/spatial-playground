# Problem Examples

This directory contains self-made, paper-style reference examples.

## Canonical examples

The canonical paper-style examples are maintained as:

- `problem-examples-deck.pptx`

Use this deck first when designing new game mechanics.

The current deck covers:

- rotation
- ferris-wheel
- mirror
- folding
- layering

## Legacy SVG status

Legacy SVG examples were removed because they were concept sketches, not readable paper-style problems.
Do not regenerate SVG examples unless explicitly requested.

Rules:

- do not trace or copy local PDF pages
- do not reuse third-party workbook text or figures
- do not present these examples as actual exam questions
- keep the examples abstract and reusable for game design
- treat the presentation deck as the canonical reference for paper-style sample problems

Use the examples as design references, not as app assets or copied exam material.
