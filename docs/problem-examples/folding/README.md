# Folding Examples

This folder contains self-made folding and unfolding references for game design.

The canonical paper-style reference deck now lives at:

- `../problem-examples-deck.pptx`

The canonical visual example is in the deck.

Use them to think about:

- a paper sheet folding over an axis
- hidden marks reappearing after unfolding
- symmetry created by a fold
- simple open/close animation

Keep the visuals simple and paper-like.
This folder should include at least one single-fold case and one folded-state variant with a different reveal pattern.
