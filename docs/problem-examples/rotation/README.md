# Rotation Examples

This folder contains self-made rotation references for game design.

The canonical paper-style reference deck now lives at:

- `../problem-examples-deck.pptx`

Use them to think about:

- arrow direction changes
- fixed-step rotation
- reference-versus-target comparisons
- immediate success feedback

Keep the visuals simple and paper-like.
This folder should contain multiple examples so the app can see both simple turn-counting cases and wheel-like cyclic cases.
